Selected Projects

Discrete Op Amp

This is a personal project I am doing to challenge myself to design a general-purpose discrete op amp. Over the summer I had read 'Analysis and Design of Analog Integrated Circuits' by Gray, Hurst, Lewis, and Meyer, and wanted to create something that incorporated all that major fundamentals I had learned. I have also always been intrigued by the "building blocks" of our world, be it in physics or in technology so being able to take a deeper look into how op amps actually work after taking an introductory electronics course has been a really fun learning experience. I have a working simulation in LTSpice and a lot of handwork to back it up, but after mixed results on a breadboard I have made and ordered a PCB... awaiting arrival!

Tools: LTSpice, KiCad • Op Amp Report • opamp_schematic

DSP Project Reports

Weekly project reports I completed for my Digital Signal Processing class. These include theoretical work and implementation in MATLAB of both FIR and IIR filters, the discrete time fourier transform using circular convolutions, the fast fourier transform, and determinig the power spectrcal density from the autocorrelation of a function.

Tools: MATLAB • Find PSD Using FFT • FIR Filter Design • Compensation Filter • Quantizer SNR

VLSI Design

These are the two projects I had done while taking a VLSI Design course last year. The first project uses shift registers to implement a serial adder, while the second project uses custom shift registers, muxes, and a carry-ripple adder to implement a binary division algorithm.

Tools: Cadence Virtuoso • Shift Register • Binary Divider

RISC-V Control Unit

System Verilog implementation of a single-cycle RISC-V control unit; synthesized with Synopsys and performed static timing analysis. Produced testbenches and coverage reports. Lengthy semester-long report describing design methodology and iteration process, with verification steps performed along the way.

Tools: Verilog, Synopsys • RISC-V Control Unit
